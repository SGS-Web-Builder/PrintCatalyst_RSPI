Step 1 — Connect your domain or subdomain
  1. Add your domain to Cloudflare. Create a Cloudflare Tunnel and install its Windows connector on this shop PC using the Administrator PowerShell command Cloudflare provides.
  2. Add a published application route: hostname print.yourshop.com, service type HTTP, service URL localhost:8080 (use your app's port). Leave the path empty so the portal and payment webhooks reach this app.
  3. Select Cloudflare below, enter https://print.yourshop.com, save, then click Verify origin. Test the QR on a phone using mobile data.
  4. Once verified online, open Payments for Step 2. Local IP access remains available for local testing; Razorpay requires a public HTTPS domain.

Saving here does not install or start Cloudflare. Its connector runs as a separate Windows service. Mark offline only changes this app's status; stop the Cloudflare service to disconnect the public route. Do not add a login challenge to customer or webhook routes.

Step 2 — Connect Razorpay

Open Step 1: domain & QR setup

Checking domain connection…

Verify your public HTTPS domain in QR setup first. Then open Razorpay Account & Settings → API Keys. Start with Test Mode; Live Mode uses a different key pair.

Razorpay credentials

Get these from your Razorpay Dashboard → Settings → API Keys.

Keep a secure copy before leaving this page. Generating a replacement only takes effect when you save; update Razorpay with the replacement too.

Step 3 — Register the webhook in Razorpay
  1. Save the connection above. Copy its webhook URL and the generated secret.
  2. In Razorpay, select the same Test or Live Mode as your keys. Open Account & Settings → Webhooks → Add New Webhook.
  3. Paste the URL and secret, select the events below, then create the webhook.
  4. Complete a customer payment in Test Mode. Check successful webhook delivery in Razorpay and confirm the corresponding order becomes paid in this dashboard.
  5. When ready, repeat with Live Mode keys and a Live Mode webhook. Keep this PC and both Windows services running.
